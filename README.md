## About The Project 📚
This project is created as a final project of sound syntehsis course in Udayana University. The main feature of this project is playing combinations of synthetic ambient sound that can be customized as desired.

## Building The Project 🍳

### 1. Clone the Repository
Clone this repository by running:
```bash
git clone https://github.com/KrustyCode/petrichor.git && cd pretrichor
```

### 2. Install Dependencies
Ensure needed libraries are installed on your system: <br>
(Optional) Create a virtual environment and activate it, then run the following:
```bash
pip install -r requirements.txt
```
  
### 3. Open the Project
Navigate to the project folder and run the `app.py` file in your terminal:
```bash
python app.py
```
